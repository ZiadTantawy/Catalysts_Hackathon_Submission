# Catalysts — More than a Hack 2027, Phase 1: Ball Possession

Team **Catalysts**' submission: a label (`H`, `A`, `D` or `X`) for every frame of the tactical
video of FC Barcelona vs Athletic Club.

Work in progress. This README will describe the approach, the data used and how to reproduce
`Catalysts.csv` from the organisers' data bundle.

## Data

The match data is not in this repository and must not be added to it. Unpack the organisers'
bundle into `data/` (gitignored), keeping the file names it arrives with.
